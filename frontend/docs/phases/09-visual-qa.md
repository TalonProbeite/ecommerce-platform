# Phase 09 — Visual QA & Final Polish

## Goal
Perform a product-level UI review and fix only issues that materially improve quality.

## Read first
- `AGENTS.md`
- `docs/RENTIFY_MASTER_SPEC.md` sections 4, 16–18, 33–35

## Workflow
1. Start the app.
2. Use Antigravity `/browser` to inspect the major public, customer, and staff routes.
3. Check desktop, tablet, and mobile layouts.
4. Review typography, spacing, hierarchy, focus states, empty/loading/error states, and visual consistency.
5. Apply the `web-design-guidelines` skill for an explicit UI/accessibility review.
6. Apply React best-practice guidance to avoid obvious performance regressions.

## Constraints
Do not redesign working pages merely for novelty. Preserve the Rentify visual direction and avoid generic “AI slop” patterns.
