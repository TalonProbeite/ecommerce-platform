# Phase 03 — Marketplace Catalog

## Goal
Make `/catalog` the strongest consumer-facing surface of Rentify.

## Read first
- `AGENTS.md`
- `docs/RENTIFY_MASTER_SPEC.md` sections 3–5, 11, 16–18, 32, 35

## Tasks
- marketplace intro/header
- search/filter controls where useful
- responsive equipment grid
- premium product cards with imagery, name, description, price, availability metadata, rental CTA
- empty/loading/error states
- reusable catalog primitives and mock data

## Constraints
Keep business data mocked unless an exact API is specified. Do not turn the catalog into an admin table. Do not introduce a second design language.
