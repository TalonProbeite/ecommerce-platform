# Аналитика просроченных аренд (P10)

## GET /api/v1/analytics/overdue-rentals

Возвращает позиции заказов, которые выданы клиенту (`item_status = 'issued'`),
ещё не возвращены (`returned_at IS NULL`) и срок аренды которых уже истёк
(`rental_end_at < now`). Время `now` берётся из `Clock` на момент чтения.

Эндпоинт только читает данные и не изменяет состояние заказа.

### Доступ

Требуется JWT в заголовке `Authorization: Bearer <token>`. Маршрут доступен
только ролям `admin` и `analyst`. Остальные роли получают `403`.
Без токена или с невалидным токеном — `401`.

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `store_id` | uuid | нет | Фильтр по магазину заказа (`orders.store_id`) |
| `cursor` | string, до 512 символов | нет | Курсор следующей страницы из `meta.next_cursor` |
| `limit` | integer, 1–100 | нет | Размер страницы, по умолчанию 20 |

Сортировка: `rental_end_at` по возрастанию, затем `id` позиции по возрастанию.

### Ответ 200

```json
{
  "data": [
    {
      "order_id": "77777777-7777-4777-8777-777777777771",
      "item_id": "01930000-0000-7000-8000-000000000301",
      "product_id": "33333333-3333-4333-8333-333333333333",
      "product_name": "Drill",
      "store_id": "22222222-2222-4222-8222-222222222222",
      "customer_id": "11111111-1111-4111-8111-111111111111",
      "quantity": 1,
      "rental_end_at": "2026-12-02T10:00:00.123456+00:00",
      "overdue_hours": 2
    }
  ],
  "meta": {
    "next_cursor": null,
    "count": 1
  }
}
```

Поля элемента:

| Поле | Тип | Описание |
|---|---|---|
| `order_id` | uuid | Идентификатор заказа |
| `item_id` | uuid | Идентификатор позиции заказа |
| `product_id` | uuid | Идентификатор товара |
| `product_name` | string | Название товара на момент заказа |
| `store_id` | uuid | Магазин заказа |
| `customer_id` | uuid | Клиент заказа |
| `quantity` | integer | Количество единиц в позиции |
| `rental_end_at` | string | Конец аренды, ISO 8601 с микросекундами и смещением, UTC |
| `overdue_hours` | integer | Полных часов просрочки, округление вверх; `0`, если позиция не просрочена |

`meta.next_cursor` — непрозрачная строка для следующей страницы или `null`,
если страница последняя. `meta.count` — количество элементов в `data`.

### Семантика просрочки

- Позиция просрочена, если `rental_end_at < now`. Позиция с
  `rental_end_at == now` не считается просроченной.
- `overdue_hours = ceil((now - rental_end_at) / 3600 секунд)`, минимум `1`
  для любой положительной просрочки. Значение вычисляется на чтении и не
  хранится в базе.

### Коды ошибок

| Код | Причина |
|---|---|
| 401 | Нет заголовка `Authorization`, токен невалиден или истёк |
| 403 | Роль не `admin` и не `analyst` |
| 422 | Невалидный `cursor`, `store_id` не uuid, `limit` вне 1–100 |
| 429 | Превышен лимит 60 запросов в минуту на пользователя |

Ошибки 403 и 422 отдаются как `application/problem+json`:

```json
{
  "type": "about:blank",
  "title": "Unprocessable Entity",
  "status": 422,
  "detail": "The cursor is malformed."
}
```

### Индекс

Чтение опирается на частичный индекс
`order_items_overdue_idx (rental_end_at, id) WHERE item_status = 'issued' AND returned_at IS NULL`.
